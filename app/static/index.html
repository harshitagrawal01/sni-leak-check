Does your hostname leak on the wire?

HTTPS encrypts what you send. It does not, by default, hide which site you asked for. Enter a domain and find out whether its name travels in the clear, and whether it publishes an Encrypted ClientHello config that would hide it.

Try: crypto.cloudflare.com cloudflare.com github.com

What this checks

Every ordinary TLS handshake begins with a ClientHello that names the site you want, in a field called the Server Name Indication (SNI). It is sent before any key exists, so it is readable by anything on the network path. That is how domain-based blocking and filtering work without breaking the encryption itself.

Encrypted ClientHello (ECH) fixes this by publishing a public key in DNS ahead of time; a capable client uses it to encrypt the real hostname inside an outer ClientHello that carries only a generic cover name. This tool reports whether a domain publishes such a config. It reads public DNS only, sends nothing to the site, and keeps no record of what you type.

One caveat worth knowing: ECH only buys real privacy when your DNS lookups are encrypted too, otherwise the name simply leaks from the DNS query instead.
